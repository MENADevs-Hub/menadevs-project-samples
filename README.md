# MENADevs Project Samples

This repository is a curated reference collection of sample projects and technical tasks produced for MENADevs. It brings varied evaluation environments, benchmark tasks, datasets, and implementation samples into one consistent structure for portfolio and client-review purposes.

Each entry under [`projects/`](projects/) is self-contained. Supplied project artifacts are preserved as received; the project-level README files provide a concise orientation to each sample.

## Project index

| Project | Description |
| --- | --- |
| [Electronic Store Evaluation Environment](projects/electronic-store-evaluation-environment/) | Electronic-store evaluation artifacts, including a Python entry sample, an ERD, workflow documents, and supporting visuals. |
| [Code Corpus Project](projects/code-corpus-project/) | A five-project corpus of Python and Node.js command-line and data-processing samples with tests and project metadata. |
| [Grafana Loki 21237](projects/grafana-loki-21237/) | A Phoenix BPO task based on Grafana Loki pull request #21237, preserving the supplied Loki source tree and task context. |
| [TBench Sample 2](projects/tbench-sample-2/) | A Dockerized Node.js benchmark task for correcting deterministic email-suppression decisions, supported by Python tests. |
| [Ultra Long Horizon Sample Work](projects/ultra-long-horizon-sample-work/) | A long-horizon Rust task focused on implementing the SQL layer of a distributed database, with evaluation tooling and recorded runs. |
| [SMILE Dataset](projects/smile-dataset/) | An Excel dataset containing sample SMILE tasks. |
| [Election Results Reconciler](projects/election-results-reconciler/) | SkillBench evaluation material for reconciling election records, together with the additional college-shortlisting task bundled in the source archive. |
| [Mars Transfer Planner Skill](projects/mars-transfer-planner-skill/) | A SkillBench mission-planning task combining orbital calculations, PostgreSQL-backed data, Python skills, and Docker tooling. |
| [Network Threat Forensics](projects/network-threat-forensics/) | A network-forensics task covering DNS tunneling, C2 beaconing, lateral movement, and data exfiltration analysis. |
