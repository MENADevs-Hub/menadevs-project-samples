# Code Corpus Project

This corpus contains five standalone, testable sample repositories spanning Python data processing and command-line applications, plus Node.js command-line tools.

## Included samples

- `customer-data-cleaning-pipeline-main` — configurable Python customer-data cleaning and validation pipeline.
- `inkwell-cli-notes-main` — Python command-line notes application.
- `node-dir-tree-main` — Node.js directory-tree command-line utility.
- `node-todo-cli-main` — Node.js command-line task manager.
- `py-md-toc-main` — Python Markdown table-of-contents utility.

Each included sample retains its own README, tests, dependency metadata, and supporting configuration.
