## Feature Implementation Roadmap

This section outlines the phased approach to increasing SQL engine complexity, with feature descriptions for each mechanism.

### 1. Scalar Function Registry + Core Built-ins

- **Description:** Registry for scalar functions (length, lower, upper, trim, abs, round, ceil, floor, coalesce, nullif, now). Enables extensible function lookup and evaluation.

### 2. CASE Expressions

- **Description:** Support for simple/searched CASE ... WHEN ... THEN ... ELSE ... END expressions in queries.

### 3. IN / BETWEEN Predicates

- **Description:** Implement IN, NOT IN, and BETWEEN predicates for filtering in WHERE/HAVING.

### 4. EXISTS and Scalar Subqueries

- **Description:** Support EXISTS, NOT EXISTS, and scalar subqueries in WHERE and SELECT.

### 5. Non-recursive CTEs (WITH)

- **Description:** Implement WITH clause for non-recursive common table expressions.

### 6. UNION ALL / UNION

- **Description:** Support UNION ALL and UNION for combining result sets.

### 7. Upsert (ON CONFLICT)

- **Description:** Implement INSERT ... ON CONFLICT DO UPDATE/NOTHING for upsert semantics.

### 8. CHECK Constraints

- **Description:** Support CHECK constraints for row-level predicate enforcement.

### 9. ALTER TABLE Basics

- **Description:** Implement ALTER TABLE for add/drop column, defaults, nullable changes, index add/drop.

### 10. Window Functions

- **Description:** Support window functions (row_number, rank, dense_rank, lag, lead, running aggregates).
