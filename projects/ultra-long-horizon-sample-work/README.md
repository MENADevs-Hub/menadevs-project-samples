# Ultra Long Horizon Sample Work

This long-horizon evaluation sample centers on implementing the SQL engine for `toydb`, a distributed database written in Rust. The task covers parsing, planning, optimization, execution, joins, aggregation, sessions, and integration with the existing storage layer.

## Technology and structure

- Rust SQL-engine task definition and source environment under `sql-engine/`.
- Python evaluation scripts and Docker Compose configuration.
- Recorded job runs, trajectories, test output, and evaluation results under `jobs/`.
- The supplied Python virtual environment and package metadata under `.venv/`.

All recorded artifacts and environment files are preserved as supplied for reference and reproducibility.
