# Network Threat Forensics

This SkillBench task evaluates investigation of a week-long network-security incident using NetFlow and DNS data.

## Technology and structure

- Python analysis and synthetic-data generation tooling.
- CSV datasets for network flows and DNS queries.
- Detection guidance for DNS tunneling, C2 beaconing, lateral movement, and data exfiltration.
- Docker configuration, automated output tests, and recorded evaluation artifacts.

The expected result is a structured forensic report identifying compromised hosts, infrastructure, detection evidence, and an incident timeline.
