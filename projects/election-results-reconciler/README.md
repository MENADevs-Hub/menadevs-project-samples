# Election Results Reconciler

This SkillBench package primarily evaluates reconciliation of certified election results against manually entered tally sheets. The task covers fuzzy precinct matching, vote-count validation, discrepancy classification, severity assignment, and JSON audit reporting.

## Technology and structure

- Python-oriented skill guidance, task instructions, and output tests.
- Docker-based evaluation environments.
- Recorded evaluation jobs and agent trajectories.
- A separately scoped college-application shortlisting task that was bundled in the original archive and is preserved here unchanged.
