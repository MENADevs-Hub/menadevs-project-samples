# Mars Transfer Planner Skill

This SkillBench task evaluates planning a 2026 cargo mission to Mars using mission data stored in PostgreSQL.

## Technology and structure

- Python skills for orbital mechanics, fuel budgeting, cost estimation, mission timelines, and database queries.
- PostgreSQL-backed mission constraints and reference data.
- Docker-based evaluation tooling and automated output tests.
- Recorded job runs and generated analysis artifacts.

The task combines data retrieval with Hohmann-transfer calculations, spacecraft and fuel-provider selection, cost modeling, and timeline generation.
